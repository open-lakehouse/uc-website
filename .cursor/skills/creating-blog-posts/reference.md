# Blog rich-content reference

Some posts (the two 2026 MDX posts) were generated by an external "docs-factory" tool. Hand-written posts use the same constructs. Styles live in `src/components/blog/blog-rich.css`.

## Callouts (`.md` and `.mdx`)

`src/lib/remark-callouts.mjs` renders container directives as styled `<aside>` boxes. Put the opening and closing `:::` on their own lines, and leave a blank line before the closing `:::` when the callout ends with a list so Prettier keeps the fence in place.

```markdown
:::warning
Using local storage for managed locations requires Docker and the host to resolve paths to the same location.
:::

:::tip[Faster local setup]
Text with **Markdown**, `code`, links, and fenced code blocks.
:::
```

| Type      | Default heading | Use for                              |
| --------- | --------------- | ------------------------------------ |
| `tldr`    | TL;DR           | Key takeaways at the top of the post |
| `tip`     | Tip             | Shortcuts and recommended practice   |
| `note`    | Note            | Side information                     |
| `info`    | Info            | Requirements and prerequisites       |
| `warning` | Warning         | Things that commonly go wrong        |
| `caution` | Caution         | Experimental or unstable features    |
| `danger`  | Danger          | Data loss or security risks          |

`[Label]` overrides the default heading. Callouts can be nested inside `<JourneyStep>`.

## Step timeline (`.mdx` only)

`<Journey>` renders a numbered vertical timeline; each `<JourneyStep step="…">` is one step, and the step title comes from the `step` prop. The post page provides these components (`src/components/blog/index.ts`), so MDX posts use them without imports. Posts from docs-factory import them as `@/components/blog/*.astro`; the build drops those lines (`plugins/post-module.ts`), so leave them as they are.

````mdx
<Journey>
  <JourneyStep step="Configure Spark with Delta and Unity Catalog">
    One or two sentences on what this step does.

    ```python title="read_write_delta_spark.py"
    spark = SparkSession.builder.getOrCreate()
    ```

  </JourneyStep>

  <JourneyStep step="Query your data">
    ```python title="read_write_delta_spark.py"
    spark.sql("SELECT * FROM unity.default.events").show()
    ```

  </JourneyStep>
</Journey>
````

- Indent step content four spaces and leave a blank line before `</JourneyStep>`, as Prettier does.
- Keep `step` titles to plain text. They do not appear in the TOC.
- Use a Journey for linear, hands-on procedures of 3 to 7 steps. Explanations belong in normal `##` sections.

## Interactive diagrams (`.mdx` only)

```mdx
<LikeC4View
  viewId="ucDeltaApi_managedTableFlow"
  alt="What the diagram shows, in a sentence or two."
/>
```

`viewId` must exist in `public/likec4/likec4-webcomponent.mjs`, a generated bundle from the docs-factory pipeline. It currently contains only `ucDeltaApi_managedTableFlow`. For a new diagram, use a static image (`![Alt text](./diagram.png)`) unless the user can regenerate that bundle. `alt` is optional; it becomes a visually hidden caption for screen readers and search.

Trestle environment diagrams come from the docs-factory emitter only:

```mdx
<TrestleView src="/trestle/<slug>/<env>/diagram.trestle-graph.json" alt="…" />
```

`src` must exist under `public/`, in the same letter case: page URLs are lowercase, but files keep their names, and Vercel serves them case-sensitively. The emitter ships the snapshot and `public/trestle/trestle-webcomponent.mjs` with the post. Don't hand-author one.

## Code blocks

Fences render like the docs' code blocks: Shiki highlighting in the page's light or dark theme (`plugins/shiki.ts`), a copy button, and the language top-right (`src/components/docs/code-block.tsx`). Options after the language:

| Syntax                      | Effect                                                     |
| --------------------------- | ---------------------------------------------------------- |
| `title="server.properties"` | Filename header (use for files the reader creates)         |
| `collapse`                  | Starts collapsed behind a "Show code" (or filename) toggle |

Use a fence without a language for program output. Line and term highlighting (`{2,5-7}`, `ins=`, `del=`, `"term"`) and `frame=` aren't supported. Don't copy docs-factory metadata such as `srcpath=` or `srcregion=`; this site ignores it.

## Tables

GFM tables are styled dark. Inline HTML in cells (`<ul><li>…</li></ul>`) works in both `.md` and `.mdx`. Prettier realigns table columns, so don't hand-align them.
